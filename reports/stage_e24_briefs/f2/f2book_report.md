## Record schema (E22-F2-ledger/1)

**Identity and fingerprints**
- date, prev_record_sha256, record_sha256 (via forward.ledger).
- schema, test_id.
- config_sha256: canonical JSON of {schema, config_f2, tables_f2}. config_f2 holds both feeds, so the
  operative feed is not part of it.
- warmup_sha256.
- feed: the operative feed (runtime input).
- declared_closed.

**Accrual and missing days**
- accrual_days (d) and accrual_base (the last record that is not a missing day).
- missing_day, missing_reason.

**Market data**
- bars: close, ret and prev_date for every delivered symbol, including BIL on a BIL-only missing day.
- cash.r_c.

**Positions, fills and costs**
- positions_before_fills (after the section 5 share update) and share_update.
- fills (legs).
- expired_orders.
- costs: half_spread, plus sec_fee, finra_taf and cat_fee, each rounded up per session; then
  commission and total.

**P&L**
- pnl: excess, shorts, leverage, costs, late_ca.
- net_pnl = the sum of the five.
- pnl_by_symbol.

**Late corporate actions**
- late_ca_input.
- late_ca entries: key, session, shares_held_into, extra_shares, value_price, long_notional_ex_usd,
  dr_c, pnl_usd, booked.
- late_ca_skipped.
- ca_applied and ca_other (when the source offers fetch_day). Since wave 2 (Q23), ca_applied is
  {symbol: [{symbol, type, ex_date, amount_or_ratio}]}: every action counted in that symbol's r,
  with a split's ratio or a distribution's per-share amount; a missing day's record stores it too.

**Targets and exposure**
- positions, targets, orders.
- signals.
- exposure: idm, n_live, cap_usd, unrounded_gross_usd, cap_scale, cap_bound, second_check (with
  float_trims), target_gross_usd, held_gross_usd, long and short notional held into t.

**Flags**
- Data problems and late_ca only. cap_bound lives in exposure, so flagged days and cap days stay
  separate.

## Questions and rulings

Lead rulings, 2026-10-18.

### Accepted as implemented

- **Q1 (RULED, accepted).** If the share-update factor is within 1e-9 of 1, it is set to 1. This is a
  float-noise guard (config numerics.share_update_tolerance).
- **Q2 (RULED, accepted).** The position after a fill is target + (q_updated - q_prev). The order's
  share difference fills unchanged, and the event's shares are kept.
- **Q3 (RULED, accepted).** For an ETF with no bar, the cash part -N_i x r_c accrues on the gap day
  while BIL has a bar. N_i x r_i accrues when the data returns.
- **Q4 (RULED, accepted).** BIL missing: the r_c parts are 0 that day. When BIL returns, r_c spans
  the gap and is applied to the notional held into the return day. Borrow and leverage accrue daily.
- **Q6 (RULED, accepted).** N_i after a gap uses the last recorded raw close. A prev_date that differs
  from the stored history is flagged prev_date_mismatch:SYM.
- **Q8 (RULED, accepted; now in the text).** Step 2's G covers only the instruments that get a new
  target. Step 5's gross includes carried positions at their last close.
- **Q10 (RULED, accepted).** Off-grid positions held inside the band are rounded by step 4, which
  can create a small order.
- **Q11 (RULED, accepted).** Fees are rounded up as ceil(round(x x 100, 6)) / 100, per session and per
  fee type (config numerics.fee_cent_rounding_guard).
- **Q12 (RULED, accepted).** A fractional short is truncated toward zero, which gives a fractional
  buy-to-cover.
- **Q13 (RULED, accepted).** The verdict is abandoned when records carry different config, warm-up or
  schema values. The feed was added to the same check; see Q22.
- **Q14 (RULED, accepted).** Late-action input, dedupe and deferral work as implemented:
  - the endpoint is queried from 31 days before the first record, plus a manual `--late-ca` list;
  - an action is booked only if its ex_date falls in a recorded session's span;
  - silent skips: already handled, already inside a recorded r, outside every recorded session, or
    not held;
  - deferral on a missing day;
  - an error on conflicting inputs.
- **Q19 (RULED, accepted).** A re-run re-reads the source and raises LedgerConflictError if the
  answer changed. late_actions=None reuses the stored input.
- **Q20 (RULED, accepted).** Other corporate-action types without a number carry amount_or_ratio 0.0.
