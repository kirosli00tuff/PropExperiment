# FeatureCoder (Coder-A features) readings, Stage E.33

Every protocol detail feat33.py / build_features33.py had to read one way. Protocol:
reports/stage_e32_discovery_protocol.md (sha256 c4ffb9d7...). Each entry: the protocol line, the
readings considered, the choice (tagged `# READING FA-<n>` in the code where it lives), and why it
is the conservative one. Facts marked "measured" are structural counts on real records (book
states and record counts only; no label, return or outcome), read through guard33/data33.
