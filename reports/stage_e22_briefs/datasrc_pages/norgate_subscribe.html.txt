ASCII (TXT/CSV) note: Only historical price data (but not other data features) may be exported in ASCII format. 
CandleScanner note: CandleScanner integration was developed by Lempart/CandleScanner. The features and capabilities of Norgate Data that are exposed by CandleScanner may not incorporate all features of Norgate Data.
EdgeRater PRO note: EdgeRater Pro integration was developed by EdgeRater, LLC. The features and capabilities of Norgate Data that are used by EdgeRater PRO may not incorporate all features of Norgate Data.
MetaStock format note: Only historical price data (but not other data features) may be exported in MetaStock "Legacy" format. 
The MetaStock "Legacy" format can be used by older versions of MetaStock™ (e.g. versions 9, 10 and 11) as well as by recent versions (e.g. 15, 16, 17 and 18). Many other charting/analysis applications can also read this format.
Python note: Only Python running on Windows is currently supported.
QuantumX note: QuantumX integration was developed by Trading Mastery School/QuantumX Software LLC. The features and capabilities of Norgate Data that are used by QuantumX may not incorporate all features of Norgate Data.
RealTest note: RealTest integration was developed by Marsten Parker/RealTest. 
The features and capabilities of Norgate Data that are used by RealTest are shown in RealTest documentation.
Share Trade Tracker note: Only available to clients of The Chartist Trading System Mentor Course. The features and capabilities of Norgate Data that are used by Share Trade Tracker may not incorporate all features of Norgate Data.
Stator note: Stator integration was developed by Anfield Capital. The features and capabilities of Norgate Data that are used by Stator may not incorporate all features of Norgate Data.
SystemTrader note: SystemTrader integration was developed by Lempart/CandleScanner. The features and capabilities of Norgate Data that are exposed by SystemTrader may not incorporate all features of Norgate Data.
TuringTrader note: TuringTrader integration was developed by Bertram Solutions. The features and capabilities of Norgate Data that are used by TuringTrader may not incorporate all features of Norgate Data.
Updata Analytics note: Updata Analytics integration was developed by Updata. The features and capabilities of Norgate Data that are exposed by Updata Analytics may not incorporate all features of Norgate Data.
XLQ2 note: XLQ2 integration was developed by QMatix. The features and capabilities of Norgate Data that are used by XLQ2 may not incorporate all features of Norgate Data.
Zipline note: Only Zipline running on Windows is currently supported.
