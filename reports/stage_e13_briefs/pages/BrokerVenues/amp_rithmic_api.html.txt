Rithmic R | API Key Features
R | API+
R | API™ provides its callers with a normalized view of market data and reference data and of order and execution reports across all supported exchanges. Additionally, R | API™ exposes R | Trade Execution Platform’s™ timestamps which have µsecond granularity, enabling a proprietary algorithmic trading program incorporating R | API™ to make its own latency calculations on which it may take appropriate action.
R | API+™ is R | API™ but with access to advanced features of R | Trade Execution Platform™. A program that incorporates R | API+ gains access to R | Trade Execution Platform’s™ custom time, tick, volume and range bars, symbol look-ups and server side trailing stops, OCOs and brackets.
